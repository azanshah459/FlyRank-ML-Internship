# FlyRank ML Internship

This repository documents my learning journey, assignments, experiments, and practical work completed during my **Machine Learning Internship at FlyRank**.

The internship focuses on practical **Machine Learning, AI fluency, data analysis, prompt engineering, responsible AI collaboration, and search intelligence**. The repository contains my weekly assignments, notebooks, experiments, documentation, and capstone work.

The goal is not only to complete assignments, but to build a reproducible record of how I frame problems, work with real data, collaborate with AI tools, validate results, and communicate technical findings honestly.

## 🎯 Internship Objectives

During this internship, I am working to:

- Develop practical Machine Learning skills.
- Learn how to frame real-world problems as ML tasks.
- Work with real-world search and content-performance data.
- Build and evaluate ML baselines and models.
- Practice responsible and effective AI collaboration.
- Improve prompt engineering skills.
- Learn data contracts, feature engineering, validation, and leakage detection.
- Develop research and technical communication skills.
- Build reproducible ML workflows using Python and notebooks.
- Turn analytical results into actionable recommendations.
- Deploy ML research as a public-facing research paper.
